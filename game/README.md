# game/（Godotプロジェクト）

gahoo-shooterのゲーム本体。[Godot](https://godotengine.org/) 4系を想定。

## 開き方

1. [Godot](https://godotengine.org/download) をインストール（4.3以降推奨）
2. Godotエディタの「Import」からこのフォルダ内の `project.godot` を選択して開く
3. `scenes/main.tscn` を実行（F6またはF5）すると、タイトル画面が表示される

## 現在の状況（実装計画 第1弾：ミニマム動作版）

`gahoo-company/gamedev/gahoo-shooter-plan-01.md` の実装計画に沿って、以下を実装済み。

- 自機（タップ/ドラッグで移動、矢印キー/WASDはデバッグ用、自動発射）
- 弾（自機から自動発射、画面外で消滅）
- 敵（直進のみの1種類、画面上部からランダムなX座標で出現）
- 当たり判定（弾が敵に当たると撃破、敵が自機に触れると被弾・残機減少・無敵時間）
- スコア表示・残機表示
- ステージ進行（敵を10体倒すとクリア）
- タイトル画面 → プレイ → ゲームオーバー/クリア画面 → タイトルへ戻る導線

**未検証**：この環境にはGodotエディタが無いため、実際にGodot上で実行しての動作確認・Android実機での確認はまだ行っていない。手元のGodotエディタで開いて動作を確認してください（`gamedev/gahoo-shooter-plan-01.md`のテスト計画参照）。

**次フェーズのスコープ外**（未実装）：パワーアップ、ボス、複数ステージ、敵の複数パターン、広告SDK統合、バックエンド（スコア保存）連携。

## 構成

```
game/
├── project.godot
├── scenes/
│   ├── main.tscn      # ゲーム進行管理（タイトル/プレイ/ゲームオーバー/クリア）
│   ├── player.tscn     # 自機
│   ├── bullet.tscn     # 自機の弾
│   └── enemy.tscn      # 雑魚敵
├── scripts/            # 上記シーンに対応するGDScript
└── assets/             # 画像・音声等（今後追加、現在は図形描画のみで代用）
```

見た目は画像アセットの代わりに `_draw()` によるシンプルな図形描画（自機＝緑の三角形、敵＝赤い四角、弾＝黄色い円）で代用している。アセット（スプライト画像等）を用意した際に差し替える。
