# game/（Godotプロジェクト）

gahoo-shooterのゲーム本体。[Godot](https://godotengine.org/) 4系を想定。

## 開き方

1. [Godot](https://godotengine.org/download) をインストール（4.3以降推奨）
2. Godotエディタの「Import」からこのフォルダ内の `project.godot` を選択して開く
3. `scenes/main.tscn` を実行（F6またはF5）すると、タイトル画面が表示される

## 現在の状況

### 実装計画 第1弾：ミニマム動作版（`gamedev/gahoo-shooter-plan-01.md`、実機確認済み）

- 自機（画面上の方向ボタン／タップ・ドラッグ／矢印キー・WASDで移動、自動発射）
- 弾（自機から自動発射、画面外で消滅）
- 当たり判定・スコア表示・残機表示
- タイトル画面 → プレイ → ゲームオーバー/クリア画面 → タイトルへ戻る導線

### 実装計画 第2弾：敵パターン・ボス・複数ステージ（`gamedev/gahoo-shooter-plan-02.md`）

- **敵パターン3種**（`scripts/enemy.gd`の`Pattern`）：直進・ジグザグ（左右蛇行）・トラッカー（自機狙い）
- **ボス**（`scenes/boss.tscn`・`scripts/boss.gd`）：各ステージ末尾に1体出現。左右移動しながら自機を狙う弾（`scenes/boss_bullet.tscn`）を発射
- 複数ステージ構成、ステージ間の「STAGE X」表示を挟んだ自動進行、最終ステージのボスを倒すと「ALL CLEAR!」画面を表示

### 実装計画 第3弾：10ステージ化・難易度カーブ・雑魚敵の射撃（`gamedev/gahoo-shooter-plan-03.md`）

- **ステージ数を3→10に拡張**。難易度はハードコードの分岐ではなく、ステージ番号から式で算出（`enemy_spawner.gd`・`main.gd`）：
  - ボス出現に必要な雑魚撃破数：8 + (stage-1)×2（8→26体）
  - 雑魚敵の出現間隔：max(0.5, 1.2 - (stage-1)×0.08)（1.2秒→0.5秒）
  - 雑魚敵の移動速度：min(280, 160 + (stage-1)×13)（160→277）
  - 敵パターンの構成：1は直進のみ／2-3はジグザグ追加／4-6はトラッカー追加／7-10は直進を外しジグザグ・トラッカー中心に
  - ボスの体力：15 + (stage-1)×3（15→42）／発射間隔：max(0.5, 1.2 - (stage-1)×0.07)／移動速度：min(220, 100 + (stage-1)×10)
- **雑魚敵の射撃**（新要素、ステージ7以降）：`enemy.gd`に`can_shoot`・`shoot_interval`を追加。ボスと同じ弾シーン（`boss_bullet.tscn`）を直進で発射
- **最終ステージ（10）のボスは3方向スプレッド弾**：`boss.gd`の`bullet_spread_count`・`bullet_spread_angle_deg`で対応

### 実装計画 第4弾：パワーアップアイテム（`gamedev/gahoo-shooter-plan-04.md`）

画像を使わず`_draw()`の図形描画で表現。雑魚敵撃破時に15%の確率、ボス撃破時は必ず1つドロップ（`scenes/power_up.tscn`・`scripts/power_up.gd`）。

- **武器強化**（黄色い星）：自機の弾が1発→3方向（3WAY）に。30秒間
- **シールド**（水色の円）：5秒間、被弾を無効化する（既存の被弾後無敵とは別枠、`main.gd`の`shield_time_left`）
- **スピードアップ**（緑の三角）：移動速度が1.5倍。15秒間
- **残機+1**（ピンクの十字）：即座に残機+1

武器強化・スピードアップは自機自身（`player.gd`）が管理し、シールド・残機+1はゲーム進行の状態に関わるため`powerup_collected`シグナルで`main.gd`に通知する。自機の弾（`bullet.gd`）はこれまで直進専用だったが、`velocity`ベースの移動に変更し3WAY発射に対応した。

**次フェーズのスコープ外**（未実装）：広告SDK統合、バックエンド（スコア保存）連携。

### 実装計画 第5弾：ハイスコア保存（ローカル永続化）

`ConfigFile`を使い、`user://highscore.cfg`にハイスコアを保存する（`main.gd`）。Web（HTML5）書き出しでも`user://`はブラウザのIndexedDBにマッピングされ永続化される。

- タイトル画面・プレイ中（左上）・ゲームオーバー画面・全ステージクリア画面の4箇所に表示
- ゲームオーバー／クリア時、今回のスコアが保存済みハイスコアを上回っていれば更新・保存し、「NEW RECORD!」を表示
- バックエンド（サーバー側でのスコア保存・ランキング等）は引き続きスコープ外。あくまで端末（ブラウザ）内でのローカル保存

### 実装計画 第6弾：コンボ／連続撃破ボーナス・爆発以外の演出強化

- **コンボ（連続撃破ボーナス）**（`main.gd`）：雑魚敵を1.5秒（`COMBO_WINDOW`）以内に倒し続けるとコンボが継続し、2コンボ目以降はコンボ数に応じたボーナススコアが加算される（`(コンボ数-1) × 20`）。被弾する、または一定時間撃破が途切れるとコンボはリセットされる。画面上部に「COMBO x n」を表示し、更新のたびに軽く拡大するアニメーションを付けて気づきやすくした。ボス戦はコンボの対象外（撃破時にコンボを一区切りとしてリセット）
- **スコアポップアップ**（`scripts/score_popup.gd`・`scenes/score_popup.tscn`、新規）：敵・ボスを倒した位置に「+スコア」が浮かび上がってフェードアウトする演出。コンボボーナスが乗っている場合は白ではなく金色で表示し、ひと目でボーナス発生が分かるようにした
- **アイテム取得演出**（`scripts/pickup_ring.gd`・`scenes/pickup_ring.tscn`、新規）：パワーアップ取得時に、取得位置から広がって消えるリングと、取得した効果名（例：「SHIELD!」）のポップアップを表示する。爆発エフェクト（`explosion.gd`）とは別の演出として、画像を使わずコードのみで実装した

### 実機フィードバックを受けた調整（2026-08-30）

Web版をスマホで確認した際のフィードバックを受けて以下を調整。

- **操作方法**：タップ/ドラッグ操作が分かりにくいとのフィードバックを受け、**画面左下に上下左右の方向ボタン（D-pad）を追加**（`main.tscn`の`UI/DPad`、`player.gd`の`set_dpad()`）。ボタンを押している間だけその方向に移動する。タップ/ドラッグ・矢印キーも引き続き使える（優先順位：矢印キー＞D-pad＞ドラッグ）
- **画面の拡大縮小設定の不備**：`project.godot`に`window/stretch/mode`が未設定だったため、実機のブラウザウィンドウの実サイズがそのままゲーム内解像度として扱われ、①想定（480×640）より大きい画面で背景の隙間バグが再発、②自機が相対的に小さく見える、の2つの不具合が発生していた。`window/stretch/mode="canvas_items"`・`aspect="keep"`を設定し、常に480×640の論理解像度を基準に拡大縮小されるよう修正
- 自機の表示サイズも0.25→0.36倍に拡大（当たり判定も32px→40pxに合わせて調整）

## 見た目（グラフィック）

自機・敵・ボスはGemini（AI画像生成）で作成したスプライト画像（`assets/sprites/`）を使用。弾は引き続き`_draw()`によるシンプルな図形描画（黄色い円）。

- `assets/sprites/player.png`（自機、上向き、白/緑/シアン系のスペース戦闘機。256×256）
- `assets/sprites/enemy.png`（敵機、下向き、黒/赤/オレンジ系のスペース戦闘機。256×256）
- `assets/sprites/boss.png`（ボス機、下向き、黒/紫/マゼンタ系の重武装艦。384×384）

**デザイン方針（2026-08-30更新）**：背景が宇宙・星雲柄のため、当初の1942風プロペラ機デザインから、SF調のスペース戦闘機デザインに変更した。自機＝寒色系（緑/シアン）、敵＝暖色系（赤/オレンジ）、ボス＝紫/マゼンタ、と配色で敵味方・強さを区別している。

**技術メモ**：AI画像生成が出力した元画像は毎回JPEG形式で、透過を示す市松模様がそのまま画素として焼き込まれてしまう（JPEGはアルファチャンネルを持たないため）。秘書側で市松模様の背景を検出しアルファ透過に変換する前処理（境界からのフラッドフィルで背景色に一致する連結領域だけを透過化）を行い、機体内部の塗装等を誤って透過させずに背景だけを除去したPNGに変換してから`assets/sprites/`に格納している。

## 背景（縦スクロール）

`assets/backgrounds/background.png`（AI画像生成、宇宙・星雲柄、640×640、上下がシームレスに繋がるよう生成）を、同じテクスチャを縦に2枚重ねて下方向に流し続けることで、途切れなくスクロールしているように見せている（`scenes/background.tscn`・`scripts/background.gd`）。`main.tscn`の最初の子ノードとして配置し、自機・敵・弾より背面に描画される。

**技術メモ**：タイルの表示サイズ（当初480px）が画面の高さ（640px）より小さいと、タイルの継ぎ目が画面をまたぐタイミングで画面下側が一時的に覆われず隙間ができる不具合があった。タイル1枚の表示サイズを画面より一回り大きい720pxに拡大（scaleを0.75→1.125）して解消。この方式（2枚タイルでの送り直し）を使う場合、**タイル1枚の表示サイズは常に画面サイズ以上にする**必要がある。

## 演出（爆発エフェクト・被弾フィードバック）

画像アセットを使わず、コードのみで実装。

- **爆発エフェクト**（`scenes/explosion.tscn`・`scripts/explosion.gd`）：敵を撃破した位置に、広がりながらフェードアウトする円を3重に重ねて描画する簡易パーティクル。0.4秒で自動的に消える
- **被弾フィードバック**：自機が敵に触れると、①画面全体が短時間（0.25秒）小刻みに揺れる（`main.gd`の`shake_time_left`、Main自身のpositionを揺らす。UIはCanvasLayerのため揺れの影響を受けない）、②無敵時間（1.5秒）の間、自機が0.1秒間隔で点滅する（`player.gd`の`set_blinking()`）
- **スコアポップアップ**（`scenes/score_popup.tscn`・`scripts/score_popup.gd`）：敵・ボス撃破位置、アイテム取得位置から上に浮かびながらフェードアウトするテキスト。撃破時は「+スコア」、アイテム取得時は効果名を表示する
- **アイテム取得リング**（`scenes/pickup_ring.tscn`・`scripts/pickup_ring.gd`）：パワーアップ取得時に、取得位置から広がって消えるリング

## 構成

```
game/
├── project.godot
├── scenes/
│   ├── main.tscn         # ゲーム進行管理（タイトル/プレイ/ゲームオーバー/クリア/ステージ進行）
│   ├── background.tscn   # 縦スクロール背景
│   ├── player.tscn       # 自機
│   ├── bullet.tscn       # 自機の弾
│   ├── enemy.tscn        # 雑魚敵（直進/ジグザグ/トラッカー）
│   ├── boss.tscn         # ボス
│   ├── boss_bullet.tscn  # ボスの弾（雑魚敵の弾にも流用）
│   ├── power_up.tscn     # パワーアップアイテム（画像不使用）
│   ├── explosion.tscn    # 爆発エフェクト（画像不使用）
│   ├── score_popup.tscn  # スコア/取得アイテム名のポップアップ（画像不使用）
│   └── pickup_ring.tscn  # アイテム取得リング（画像不使用）
├── scripts/               # 上記シーンに対応するGDScript
└── assets/
    ├── sprites/          # 自機・敵のスプライト画像（AI画像生成、背景透過処理済み。ボスは敵スプライトを流用）
    └── backgrounds/      # 縦スクロール背景画像（AI画像生成）
```
